Write Better AI Prompts

Use this worksheet to turn vague requests into clear, testable prompts. The goal is to give the AI context, constraints, and a target format—so you get outputs you can actually use.

1) The Prompt Recipe (5 parts)

  1. Goal: What do you want? (e.g., “draft”, “summarize”, “generate options”)
  2. Context: Who/what is this for? (audience, scenario, domain)
  3. Constraints: Limits + must-haves. (length, tone, topics to avoid)
  4. Format: The shape of the answer. (bullets, table, steps, JSON)
  5. Quality check: How to judge it. (accuracy, citations, examples, rubric)
Template (copy + fill in)

You are a [role]. Help me [goal]. Context: [background + audience].
Constraints: [limits, must include, must avoid].
Output format: [exact structure].
Before answering, ask up to [N] clarifying questions if needed.

2) Examples (Why they work)

Type Example prompt Why it works
Specific

List 5 benefits of renewable energy. For each, include one sentence of explanation and one real-world example.

Clear count + structure + examples = fewer vague answers.
Context

Explain the causes of World War I for 9th graders in under 180 words, using simple language and one analogy.

Audience + length + tone constraints guide the level.
Format

Summarize “Romeo and Juliet” in exactly 3 bullets. Each bullet must start with a verb.

Format rules reduce rambling and improve scanability.
