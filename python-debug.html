Part 1 — Worked examples (with beginner-friendly explanations)

Reference

Read each broken snippet. Try to predict the error message. Then read the fix and explanation. The goal is to learn the “shape” of common Python mistakes.

Example 1 — Missing colon 
# Code that doesn't work:
def greet(name)
    print("Hello, " + name)

greet("Alice")
Fixed
def greet(name):
    print("Hello, " + name)

greet("Alice")
Why the original breaks: In Python, a colon (:) is required after any line that starts a new block of code—like a function (def), a loop (for/while), or a conditional (if). Without the colon, Python can’t tell where the “header” ends and the indented block begins, so it raises a SyntaxError.

Why the fix works: Adding : tells Python, “the next indented lines belong to this function.” The indented print becomes the function body, and calling greet("Alice") runs that body.
Example 2 — Indentation 
# Code that doesn't work:
for i in range(5):
print(i)
Fixed
for i in range(5):
    print(i)
Why the original breaks: Python uses indentation (leading spaces) to show which lines belong inside a block. After for i in range(5):, Python expects an indented “loop body”. Because print(i) is not indented, Python doesn’t know what to do next and raises an IndentationError (or complains it expected an indented block).

Why the fix works: Indenting print(i) tells Python it is part of the loop body, so it runs once per iteration. This is why Python code style matters: indentation is not just pretty formatting—it's part of the language.
Example 3 — Variable used before assignment 
# Code that doesn't work:
print(x)
x = 10
Fixed
x = 10
print(x)
Why the original breaks: A variable name like x only “exists” after you assign something to it. In the broken code, Python reaches print(x) first, but x has not been defined yet—so Python raises a NameError.

Why the fix works: By assigning x = 10 first, you create the variable in memory. Then when you print it, Python knows what x refers to.

Beginner habit: When you see a NameError, check spelling and check whether the variable is defined before use.
Example 4 — TypeError (string + int) 
# Code that doesn't work:
age = 25
print("I am " + age + " years old.")
Fixed (recommended)
age = 25
print(f"I am {age} years old.")
Why the original breaks: The + operator can concatenate strings, but only if both sides are strings. Here, age is an integer, so Python refuses to guess how to combine text and numbers and raises a TypeError.

Why the fix works: An f-string (f"...") is a safe way to build strings. Anything inside {} is evaluated and converted to text for you. That means you can insert numbers, variables, or even expressions without manual str(...) calls.

Alternative fix: "I am " + str(age) + " years old." (works, but is more cluttered).
Example 5 — Infinite loop (missing increment) 
# Code that doesn't work (never stops):
i = 0
while i < 5:
    print(i)
Fixed
i = 0
while i < 5:
    print(i)
    i += 1
Why the original breaks (or “hangs”): A while loop keeps running as long as its condition is true. The condition here is i < 5. But notice: inside the loop, i never changes, so it stays at 0 forever. That means the condition stays true forever, so the program never reaches the end (an infinite loop).

Why the fix works: i += 1 increases i each time the loop runs. Eventually i becomes 5, making i < 5 false, and the loop stops.

Beginner check: For every while loop, ask: “What changes each iteration so the condition can become false?”

Answer Key — Fixes + beginner-friendly explanations

Instructor

Each answer includes corrected code and an explanation of what went wrong and why the fix works.

Answer 1
def calculate_area(radius):
    area = 3.14 * radius ** 2
    return area

print(calculate_area(5))
Explanation: Function headers must end in :. The colon starts the indented function block. Without it, Python raises a SyntaxError.
Answer 2
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    print(num * 2)
Explanation: A for loop needs a colon, and its body must be indented. Indentation defines the loop block (what repeats each iteration).
Answer 3
def greet_user(name):
    print("Welcome, " + name)

greet_user("John")
Explanation: The function body must be indented. Without indentation, Python can’t tell which lines belong inside the function and raises an IndentationError.
Answer 4
count = 10
while count > 0:
    print(count)
    count -= 1
Explanation: while repeats while its condition is true. If you never change count, the condition stays true forever. Decrementing eventually ends the loop.
Answer 5
name = "Emma"
print(f"Hello {name} 5")
Explanation: You can’t concatenate a string and an integer with +. f-strings safely convert inserted values to text automatically.
Answer 6
def find_max(numbers):
    max_num = numbers[0]
    for num in numbers:
        if num > max_num:
            max_num = num
    return max_num

print(find_max([3, 7, 2, 9, 5]))
Explanation: The if must be inside the loop so every item is compared. The algorithm keeps the best value so far and updates it when a larger number is found.
Answer 7
my_dict = {"a": 1, "b": 2, "c": 3}
print(my_dict.get("d", "Key not found"))
Explanation: my_dict["d"] raises KeyError if the key is missing. get returns a default value instead of crashing.
Answer 8
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

print(factorial(5))
Explanation: This code is already correct. It uses recursion with a base case (n == 0) and a step that moves closer to the base case (n - 1).
Answer 9
for i in range(1, 10):
    if i % 2 == 0:
        print(f"{i} is even")
Explanation: = assigns values; == compares values. In an if, you need a comparison. i % 2 checks the remainder; even numbers have remainder 0.
Answer 10
def add_items_to_list(item, my_list=None):
    if my_list is None:
        my_list = []
    my_list.append(item)
    return my_list

print(add_items_to_list(1))
print(add_items_to_list(2))
Explanation: Default lists are created once and reused across calls, causing shared state. Using None and creating a new list inside the function gives each call a fresh list (unless you pass one intentionally).
