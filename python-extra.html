1) Core syntax & built-ins

# Define variables with different types
name = "Alice"  # A string variable holding a name
fav_num = 7    # An integer variable holding a favorite number
likes_python = True  # A boolean variable indicating if Python is liked

# Print all variables on one line, separated by spaces
print(name, fav_num, likes_python)

# Print the type of division results
print(type(3/2))  # '/' operator does floating point division, result is float
print(type(3//2)) # '//' operator does integer division (floor), result is int

# Create an empty list
lst = []
print(bool(lst))  # Empty list is False in boolean context

# Add an element to the list
lst.append(42)
print(bool(lst))  # Now list is not empty, so True

# Assign a value that is considered False in boolean context
answer = 0  # Other falsey values: "", [], None, False
print(bool(answer))  # Prints False

# Assign None to a variable (means no value)
x = None
print(type(x))  # NoneType is the type of None
print(bool(x))  # None is also False in boolean context
Explanation:
This section introduces variables of different types: strings, integers, and booleans. We print variables and check their types using type(). We also explore how Python treats empty collections and special values like None as False in conditions. This is important because Python uses truthiness to decide if something counts as True or False in if-statements and loops.

2) Strings (the everyday workhorse)

s = "python worksheet"

# Access characters by index (0-based)
print(s[0])    # First character: 'p'
print(s[-1])   # Last character: 't'

# Slice substrings: s[start:stop] (stop is exclusive)
print(s[0:6])  # Characters from index 0 to 5: 'python'
print(s[7:])   # From index 7 to end: 'worksheet'

# Slice with step: every 2nd character
print(s[::2])  # 'pto okhet'

# Common string methods
raw = " Hello, World! "
clean = raw.strip()  # Remove spaces from start and end

print(clean.lower())  # Convert to lowercase
print(clean.upper())  # Convert to uppercase
print(clean.replace("World", "Python"))  # Replace substring
print(clean.startswith("Hello"), clean.endswith("!"))  # Check start and end

# Split string into list by comma, then strip spaces
line = "apples, bananas, cherries"
parts = [p.strip() for p in line.split(",")]
print(parts)  # List of fruits

# Join list back into a string separated by commas
csv_again = ", ".join(parts)
print(csv_again)
Explanation:
Strings are sequences of characters. You can access individual characters by index or get substrings using slicing. Python strings have many useful methods like strip() to clean whitespace, lower() and upper() to change case, and replace() to substitute parts of the string. Splitting breaks a string into a list, and joining combines a list into a string. These are everyday tools for text processing.

3) Numbers

a = 17
b = 5

# Floating point division (result is float)
print(a / b)  # 3.4

# Integer division (floor division, result is int)
print(a // b)  # 3

# Modulo operator gives remainder
print(a % b)  # 2

# divmod returns quotient and remainder as a tuple
print(divmod(a, b))  # (3, 2)

# List of numbers for aggregate functions
nums = [2.3, 2.6, 2.5, 9.1]

# Round to 2 decimal places (note floating point quirks)
print(round(2.675, 2))  # 2.67 (may vary slightly)

# Minimum and maximum values in list
print(min(nums), max(nums))  # 2.3 9.1

# Sum of all numbers
print(sum(nums))  # 16.5

# Rounded sum
print(round(sum(nums), 2))  # 16.5
Explanation:
This section covers different types of division in Python: floating point division with / and integer division with //. The modulo operator % gives the remainder. The divmod() function returns both quotient and remainder. We also use built-in functions like round(), min(), max(), and sum() to work with lists of numbers. Note that floating point numbers can have small precision issues.

4) Control flow (if / for / while)

score = 87

# Conditional branching with if, elif, else
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D or below"

print(grade)

items = ["pen", "pencil", "eraser"]

# For loop with enumerate to get index and item
for i, item in enumerate(items, start=1):
    print(i, item)

# For loop with range to iterate numbers
for n in range(3):
    print("n =", n)

n = 0

# While loop with break and continue
while n < 10:
    n += 1
    if n % 2 == 1:
        continue  # Skip odd numbers
    print(n)
    if n == 6:
        break  # Exit loop when n is 6
Explanation:
This section shows how to control the flow of your program. Use if, elif, and else to make decisions. Use for loops to iterate over lists or ranges of numbers. The enumerate() function helps get both the index and the item. Use while loops to repeat actions while a condition is true. The continue statement skips the current loop iteration, and break exits the loop early.

5) Data structures: list, tuple, set, dict

nums = [3, 1, 4]

# Add elements to list
nums.append(1)          # Add single element at end
nums.extend([5, 9])     # Add multiple elements

print(nums)

# Slice first 3 elements
print(nums[:3])

# Remove first occurrence of 1
nums.remove(1)
print(nums)

# Sort list in place
nums.sort()
print(nums)

# Tuple unpacking
point = (10, 25)
x, y = point
print(x, y)

# Star unpacking to capture middle elements
a, *middle, b = [1, 2, 3, 4, 5]
print(a, middle, b)

# Sets store unique elements
a = {1, 2, 3, 3}  # Duplicate 3 removed
b = {3, 4, 5}

print(a)        # {1, 2, 3}
print(a | b)    # Union: {1, 2, 3, 4, 5}
print(a & b)    # Intersection: {3}
print(a - b)    # Difference: {1, 2}

# Dictionaries map keys to values
student = {"name": "Mina", "grade": 8}

print(student["name"])  # Access by key
print(student.get("age", "unknown"))  # Safe lookup with default

student["grade"] = 9
student.update({"club": "Robotics"})

for k, v in student.items():
    print(k, "=>", v)
Explanation:
Lists are ordered collections you can change (mutable). You can add, remove, slice, and sort them. Tuples are ordered but cannot be changed (immutable). Sets store unique items and support mathematical operations like union and intersection. Dictionaries store key-value pairs for fast lookups. Use .get() to avoid errors when a key might be missing. Looping over dictionaries with .items() gives keys and values.

6) Functions

def area_rect(w, h):
    # Calculate area of rectangle
    return w * h

print(area_rect(3, 4))
print(area_rect(w=5, h=2))

def greet(name, punctuation="!"):
    """Return a friendly greeting."""
    return f"Hello, {name}{punctuation}"

print(greet("Rae"))
print(greet("Rae", punctuation="."))

def summarize(*nums, label="sum"):
    total = sum(nums)
    return f"{label}: {total}"

print(summarize(1, 2, 3))
print(summarize(10, 20, label="total"))

def show_profile(**info):
    for k, v in info.items():
        print(k, ":", v)

show_profile(name="Noor", city="Austin", hobby="chess")

words = ["pear", "fig", "pineapple", "kiwi"]

# Sort words by length using a lambda function
by_len = sorted(words, key=lambda w: len(w))
print(by_len)
Explanation:
Functions let you group reusable code. You define parameters and return values. You can give default values to parameters. The *args syntax collects extra positional arguments as a tuple, and **kwargs collects extra keyword arguments as a dictionary. Lambda functions are small anonymous functions useful for short operations like sorting by a custom key.

8) Files (read/write)

lines = ["apples", "bananas", "cherries"]

# Write lines to a text file safely using 'with'
with open("fruits.txt", "w", encoding="utf-8") as f:
    for item in lines:
        f.write(item + "\n")  # Write each item with a newline

# Read entire file content
with open("fruits.txt", "r", encoding="utf-8") as f:
    text = f.read()
print(text)

# Read lines into a list, stripping whitespace
with open("fruits.txt", "r", encoding="utf-8") as f:
    fruits = [line.strip() for line in f]
print(fruits)
Explanation:
Use with open(...) to open files safely; it ensures files are closed automatically. Use mode "w" to write (overwriting existing content) and "r" to read. When writing, add newline characters to separate lines. When reading, you can read the whole file as a string or read line-by-line into a list, cleaning each line with strip().

9) Errors & exceptions

def to_int(text):
    try:
        return int(text)  # Try to convert text to integer
    except ValueError:
        return None  # Return None if conversion fails

print(to_int("123"))
print(to_int("hello"))

def safe_div(a, b):
    try:
        result = a / b  # Try division
    except ZeroDivisionError:
        return "Cannot divide by zero"
    except TypeError:
        return "Inputs must be numbers"
    else:
        return result  # Return result if no exceptions
    finally:
        # This block runs no matter what (cleanup)
        pass

print(safe_div(10, 2))
print(safe_div(10, 0))
print(safe_div("10", 2))
Explanation:
Errors can happen during program execution. Use try and except blocks to catch and handle errors gracefully. Catch specific exceptions like ValueError or ZeroDivisionError to respond appropriately. The else block runs if no error occurs, and finally always runs, useful for cleanup tasks.

10) Comprehensions + useful tools

nums = [1, 2, 3, 4, 5, 6]

# List comprehension with condition: squares of even numbers
evens_sq = [n * n for n in nums if n % 2 == 0]
print(evens_sq)

words = ["ant", "bear", "cat"]

# Dictionary comprehension: word lengths
lengths = {w: len(w) for w in words}
print(lengths)

names = ["Ava", "Ben", "Cy"]
scores = [10, 7, 10]

# Zip and enumerate to loop over two lists with index
for i, (n, s) in enumerate(zip(names, scores), start=1):
    print(i, n, s)

nums = [2, 4, 6]

# any() checks if any element matches condition
print(any(n % 2 == 1 for n in nums))  # Any odd number?

# all() checks if all elements match condition
print(all(n % 2 == 0 for n in nums))  # All even numbers?
Explanation:
Comprehensions provide a concise way to create lists or dictionaries from existing iterables, optionally filtering with conditions. The zip() function pairs elements from multiple lists. enumerate() adds an index to loops. any() and all() check if any or all elements satisfy a condition, useful for quick checks.

11) OOP basics (classes)

class Counter:
    def __init__(self, start=0):
        # Initialize counter value
        self.value = start

    def inc(self, step=1):
        # Increase counter by step (default 1)
        self.value += step
        return self.value

    def reset(self):
        # Reset counter to zero
        self.value = 0

    def __repr__(self):
        # String representation for printing
        return f"Counter(value={self.value})"

c = Counter()
print(c)      # Counter(value=0)
c.inc()       # Increment by 1
c.inc(4)      # Increment by 4
print(c.value)  # Current value: 5
c.reset()     # Reset counter
print(c)      # Counter(value=0)

class Rectangle:
    def __init__(self, w, h):
        self.w = w
        self.h = h

    @property
    def area(self):
        # Calculate area as property (access like attribute)
        return self.w * self.h

r = Rectangle(3, 4)
print(r.area)  # 12
Explanation:
Object-Oriented Programming (OOP) lets you create classes that bundle data (attributes) and behavior (methods). The __init__ method initializes new objects. Methods like inc() and reset() define actions. The @property decorator lets you access methods like attributes for cleaner code. The __repr__ method defines how objects are printed.
