Part 1

What is HTML?

Think of HTML as the structure of a webpage. It tells the browser what each piece of content is.

Quick notes

  • HTML stands for HyperText Markup Language.
  • It uses tags like <h1> and <p> to label content.
  • Most tags come in pairs: an opening tag and a closing tag.
  • HTML builds the structure of a page. CSS styles it. JavaScript adds interactivity.

Part 2

Meet the core tags

These are some of the first tags most people learn when starting web development.

Common beginner tags and what they do

<h1> — the main heading on a page

<p> — a paragraph of text

<a> — a link to another page or website

<ul> — an unordered list

<li> — one item inside a list

<img> — an image element
