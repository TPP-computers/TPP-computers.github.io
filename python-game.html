Worksheet: Understanding and Running the “Guess the Number” Python Game

Where it runs: Works on https://www.online-python.com/ (text-based, no extra libraries).

Overview

This worksheet explains how a simple “Guess the Number” game works in Python. The player guesses a secret number and the program responds “too high” or “too low” until the player is correct.

Complete Code for the Game

"""
Simple "Guess the Number" game in Python.
Works in any Python environment including online interpreters.
"""

import random

def guess_the_number():
    print("Welcome to Guess the Number!")
    print("I'm thinking of a number between 1 and 100.")
    number = random.randint(1, 100)
    attempts = 0

    while True:
        try:
            guess = int(input("Enter your guess: "))
            attempts += 1
            if guess < number:
                print("Too low! Try again.")
            elif guess > number:
                print("Too high! Try again.")
            else:
                print(f"Congratulations! You guessed it in {attempts} attempts.")
                break
        except ValueError:
            print("Please enter a valid integer.")

if __name__ == "__main__":
    guess_the_number()

1. Program Structure

The game logic is inside guess_the_number(). The block if __name__ == "__main__": makes sure the game starts when you run the file.

print() outputs text to the screen.

c) Creating the secret number

number = random.randint(1, 100)

randint(a, b) returns a random integer from a to b (inclusive).

d) Looping until correct

    ...

The loop continues forever until we use break.

e) Getting input safely

    guess = int(input("Enter your guess: "))
except ValueError:
    print("Please enter a valid integer.")

input() returns a string. int(...) converts it to a number. If the conversion fails, ValueError is caught and the game continues.

f) Comparing guesses

    ...
elif guess > number:
    ...
else:
    ...

Conditionals decide which message to show.

3. How to Play

  1. Run the program.
  2. Type a guess and press Enter.
  3. Use the “too high/too low” feedback to narrow it down.
  4. When correct, the game shows how many attempts it took.

4. Important Python Concepts Used

  • Functions: grouping logic into reusable blocks
  • Loops: repeating actions until a condition is met
  • Conditionals: branching logic (if/elif/else)
  • Exceptions: handling invalid input with try/except
  • Variables: storing values like number and attempts
